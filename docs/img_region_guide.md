# 객체 영역 정확성 채점 기준 (의미정확성 · `obj_bbox`·`obj_mask`·`obj_missing` 만)

묶음의 항목마다 `overlay_image` 를 **Read 로 직접 연다**. 사진 위에 박스(테두리)와 마스크(반투명 색칠)가 겹쳐 있고,
좌상단 `#번호 클래스` 가 `objects[].no` 와 같다. 객체가 0개면 겹친 것 없이 사진만 보인다.

## 판정값
`ok` 적합 · `minor` 보통(쓸 수는 있으나 다듬을 여지) · `major` 부적합(틀려서 고쳐야 함). `na` 없음.
확실히 틀린 것만 `major`, 애매하면 `minor`. 눈에 보이는 오류를 `ok` 로 넘기지 않는다.

| 키 | 보는 것 | minor 예 | major 예 |
|---|---|---|---|
| obj_bbox 객체 위치 | 박스가 대상을 제대로 감싸는가 | 테두리가 조금 넉넉하거나 살짝 잘림 | 대상의 절반만 덮음, 대상은 일부인데 화면 전체를 덮음, 옆 건물까지 포함 |
| obj_mask 분할 마스크 | 색칠 영역이 대상 모양을 따라가는가 | 가장자리가 조금 번지거나 작은 구멍 | 하늘·바닥·담장까지 크게 번짐, 대상의 큰 부분이 비어 있음, 색칠이 거의 없음 |
| obj_missing 객체 누락 | 눈에 띄는 대상이 빠지지 않았는가 | 작은 반복 문양·주변 부재 일부 누락 | 정면 현판·주요 전각·화면 중심의 석조물 등에 박스가 없음, 대상이 뚜렷한데 객체 0개 |

- 대상 클래스: 전각, 궁문, 담장, 석조물, 현판, 한자, 문양, 의례, 정원, 그림, 도면 등 라벨에 쓰이는 종류.
- 사진 전체가 한 건물 정면처럼 대상이 화면을 거의 채우면, 화면 전체 박스는 정상(ok)이다.
- 객체가 0개면 obj_bbox·obj_mask 는 ok 로 두고 누락만 본다.

## 출력
결과 파일에 항목마다 JSON 한 줄:
`{"data_id": "...", "checks": {"obj_bbox": "ok", "obj_mask": "ok", "obj_missing": "ok"}, "comment": "minor·major 면 몇 번 객체가 무엇이 문제인지 한 문장(한국어), 없으면 빈 문자열"}`
세 키만 넣는다.
