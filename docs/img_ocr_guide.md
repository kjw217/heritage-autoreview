# 현판 판독 정확성 채점 기준 (의미정확성 · 세부 항목 `ocr` 만)

묶음의 항목마다 `sheets` 의 그림(현판·한자 객체를 잘라 모은 것)을 **Read 로 직접 연다**.
그림 속 빨간 `#번호` 가 `plates[].no` 와 같다. 각 조각의 실제 글자를 `ocr_text`(판독문)·`reading`(독음, 빈 값일 수 있음)과 대조한다.

## 판정 (이미지 1건에 하나)
- `ok` 적합: 모든 조각의 판독문이 실제 글자와 맞다. 독음이 있으면 독음도 맞다.
- `minor` 보통: 쓸 수는 있으나 다듬을 여지. 예) 흐려서 한두 글자가 확실치 않음, 이체자·약자 표기 차이, 독음만 살짝 어긋남, 장식·낙관 글자 일부 누락.
- `major` 부적합: 틀려서 고쳐야 함. 예) 다른 글자로 읽음(敦化門→殷政門), 글자 순서 뒤바뀜(현판은 보통 오른쪽에서 왼쪽으로 읽는다), 글자가 빠지거나 더해짐, 독음이 판독문과 다름.
- 조각이 여럿이면 가장 나쁜 판정을 쓴다. 글자가 너무 작거나 흐려 판단할 수 없는 조각은 판정에서 빼고, 판단 가능한 조각으로 정한다(전부 판단 불가면 `minor`).
- 확실히 틀린 것만 `major`. 그림에서 글자가 잘 안 보인다고 `major` 를 주지 않는다.
- 유산명(`heritage_name`)은 참고만 한다. 현판 이름이 유산명과 달라도 그 자체로 오류는 아니다.

## 출력
결과 파일에 항목마다 JSON 한 줄:
`{"data_id": "...", "ocr": "ok|minor|major", "comment": "minor·major 면 몇 번 조각이 무엇이 문제인지 한 문장(한국어), ok 면 빈 문자열"}`
